# Engineering Principles

## Our Mission

Potential exists to help interviewers collect trustworthy evidence about candidate capability.

We do not make hiring decisions.

...

## Product Philosophy

- Evidence over scores
- Transparency over automation
- Humans remain accountable
- Every AI output is explainable

...

## Product Decision Framework

Every feature must answer:

- Does this improve evidence quality?
- Does it help interviewers make better decisions?
- Is every AI output explainable?
- Does it reduce recruiter effort?
- Can it be implemented simply?

If not, we should challenge whether it belongs.

...

## Engineering Principles

- Prefer simple architectures.
- Persist everything important.
- Every AI output is traceable.
- Eliminate mock data.
- Build for production first.
